## 🌌 Overview

A production-ready personal portfolio built with **Next.js 15**, **React 19**, **Tailwind CSS**, and **Three.js / WebGL**. Designed with an **Obsidian + Violet + Magenta + Hot Pink + subtle Peach** visual identity, inspired by modern Aceternity UI design dynamics, interactive 3D physics, and rigorous systems engineering aesthetics.

---

## ✨ Features

- **🪐 3D WebGL Constellation**: An interactive Three.js particle constellation and geometric wireframe icosahedron with mouse parallax, inertial damping, and adaptive mobile density.
- **🎯 Custom Cursor Experience**: Smooth trailing spring-physics follower ring with interactive hover expansion and touch-device detection.
- **⚡ Developer Command Terminal**: Interactive terminal modal accessible via `⌘K` or `Ctrl+K` with support for commands: `whoami`, `skills`, `projects`, `experience`, `education`, `contact`, `github`, `linkedin`, `clear`, and `exit`.
- **🎛️ Aceternity-Style 3D Pin Cards**: 3D card tilt perspective with triple concentric radar pulse rings on featured projects.
- **✨ Illuminated Moving Border Cards**: Rotating gradient light beams showcasing enterprise internship experience.
- **🧩 Bento Grid Architecture**: Visual narrative highlighting distributed job scheduling, computer vision pipelines, core CS foundations, and instant copy-to-clipboard email integration.
- **📱 Fully Responsive**: Tailored fluid layouts across mobile, tablet, and ultra-wide screens with `prefers-reduced-motion` compliance.

## 🚀 Quick Start

### 1. Clone the repository
```bash
git clone https://github.com/Kaushtubha/kaushtubham-portfolio.git
cd kaushtubham-portfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 4. Build for production
```bash
npm run build
npm start
```
